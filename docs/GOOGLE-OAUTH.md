# Phương án Google OAuth đã ngừng dùng trong bản hiện tại

Từ **1.2.0**, dự án sử dụng tiện ích Chrome/Edge để đọc giao diện Classroom và chuyển kết quả trực tiếp lên website. Không cần tạo Google Cloud Project, bật Classroom API, tạo OAuth Client ID hoặc khai báo biến `GOOGLE_CLIENT_ID`.

Xem [cách cài đặt và kết nối bằng tiện ích](CAI-DAT.md).

Bản 1.1.0 trước đây có phương án OAuth/API, đã kiểm thử với response mô phỏng nhưng chưa cấu hình Client ID thật. Mã và hướng dẫn cũ còn trong lịch sử Git và release v1.1.0; không áp dụng cho website hiện tại.
